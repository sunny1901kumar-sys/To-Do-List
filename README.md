# 📝 To Do List

A simple **To Do List** built using **HTML, CSS, and JavaScript**. It allows users to add tasks, mark them as completed, delete tasks, and filter tasks based on their status.

🌐 [**Live Demo**](https://sunny1901kumar-sys.github.io/To-Do-List/)

![To Do List Screenshot](https://github.com/sunny1901kumar-sys/To-Do-List/raw/main/Screenshot.png)

## ✨ Features

- ➕ Add new tasks
- ⌨️ Add tasks using the Enter key
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 🔄 Filter tasks by All, Active, and Completed
- 🟢 Highlights the currently selected filter
- 🚫 Prevents adding empty tasks
- 🔍 Updates the task list when a task is completed or filtered

## 🛠️ Technologies Used

- **HTML** – Structure
- **CSS** – Styling and layout
- **JavaScript** – Task logic and user interactions

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
